Note

According to the Android package installation rules, if a newer version is already installed on the system, you cannot directly reinstall an older version. To install an older version, you must uninstall the newer one first.

Please note that this process will clear your user data, including but not limited to search history, icon redemption status, etc., which we cannot restore.
