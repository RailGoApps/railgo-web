Installation

  1. Tap a button above to get the installer via Microsoft Store or GitHub Releases.
  2. Double-click the downloaded installer to run it.
  3. If a SmartScreen prompt appears, click "More info → Run anyway".
  4. Follow the setup wizard to finish.

System Requirements

  • Windows 10 1809 and above
  • At least 100 MB of free storage

  • Network connection required for live data
