Frequently Asked Questions

The most common questions are answered here. Can't find an answer? Let us know.

Basics

Is RailGo free?

Yes. RailGo's core query features are completely free with no ads. Server costs are covered by donations.

Can RailGo book tickets?

No. RailGo is an information query tool and does not support ticket booking. Please use official channels such as 12306 to book.

Is the data accurate? How often is it updated?

Data comes from official public APIs and is reliable. Timetable data is usually updated with each schedule revision; real-time data like tickets and delays refreshes at minute-level.

Features

Why can't I find a certain train?

Possible reasons: the train is suspended or seasonally inactive; it doesn't run on that day (e.g. some weekend-only services); the number was mistyped. Double-check the train number and retry.

Tickets show "available" but I can't book?

The availability RailGo shows is a snapshot at query time and may differ from actual booking time. Always refer to 12306 for real-time availability.

How often is delay info updated?

Delay status for running trains updates roughly every few minutes. Due to source limitations, it may lag by a few minutes.

Installation & Usage

Android install warns "unknown source"?

This is an Android security mechanism. Go to Settings → Apps → Special access → Install unknown apps and allow your browser or file manager to install, then retry.

How do I install on iOS?

Follow the guide on the iOS download page: install via TestFlight or an enterprise certificate, and trust the corresponding profile.

Does the Windows version need a runtime?

Windows 10 1809 and above need no extra runtime. Older systems may need the WebView2 runtime installed.

Other

How do I report bugs or suggestions?

Submit via the Report & Feedback page. We read every piece of feedback carefully.

Which railway types are supported?

All China Railway passenger services: high-speed (G), EMU (D/C), intercity (C), direct (Z), express (T), fast (K), and ordinary trains.

Are foreign railways supported?

Currently only mainland China railways. Foreign railways are not on the roadmap.
