1. How to give us feedback

A: Please submit a ticket at RailGo Center, or open an Issue in the GitHub repository for feedback. If none of the above channels are available, please email service@railgo.dev.

2. Missing train issue

A: This issue can be resolved by using RailGo V2, which no longer uses cached data and has better timeliness.

3. Inaccurate speed measurement

A: Speed data comes from the API provided by Uniapp; we are doing our best to optimize it.
