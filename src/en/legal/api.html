API Usage Terms

updateLast updated: 2024 apiAZ Studio

RailGo provides a limited public API for developers to fetch railway info in their own projects. Please read these terms before use.

warning

The API is currently in limited access and may change or shut down at any time. Not recommended for critical production paths.

1. Access

To use the API, apply for an API Key via the feedback channel. We evaluate requests based on intended use.

2. Limits

  • Rate limit: default 60 requests per minute per key.
  • Use limit: non-commercial use only; reselling data is prohibited.
  • Attribution: projects using the API must credit "Data provided by RailGo" prominently.
  • Cache limit: cached data may be kept for up to 24 hours.

3. Data Scope

The API currently provides:

  • Train schedule lookup (by train number)
  • Station-to-station train lookup
  • Station info lookup

Real-time data (tickets, delays) is not publicly available yet.

4. Disclaimer

API data comes from public sources; accuracy is subject to official releases. We don't guarantee API availability or stability and aren't liable for losses from outages or data errors.

5. Violations

The following will result in immediate key revocation:

  • Malicious requests exceeding rate limits;
  • Reselling or using data in commercial products;
  • Spoofing origins or evading limits;
  • Other behavior disrupting service stability.

6. Changes

We reserve the right to modify these terms and the API at any time, with advance notice where possible.
