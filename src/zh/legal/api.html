API 使用协议

update最近更新：2024 年 apiAZ Studio

RailGo 提供有限的公开 API 供开发者在自己的项目中获取铁路信息。使用前请阅读本协议。

warning

API 目前处于受限开放阶段，可能随时调整或关闭，不建议用于生产关键路径。

一、接入方式

如需使用 API，请先通过 反馈渠道 申请 API Key。我们将根据用途评估是否发放。

二、使用限制

  • 频率限制：默认每 Key 每分钟不超过 60 次请求。
  • 用途限制：仅限非商业用途，禁止转售数据。
  • 署名要求：使用 API 的项目需在显著位置注明「数据由 RailGo 提供」。
  • 缓存限制：缓存时长不得超过 24 小时。

三、数据范围

当前 API 提供以下能力：

  • 列车时刻查询（按车次）
  • 站站车次查询
  • 车站信息查询

实时类数据（余票、晚点）暂不对外开放。

四、免责声明

API 数据来源于公开渠道，准确性以官方为准。我们不保证 API 的可用性、稳定性，因 API 中断或数据错误造成的损失我们不承担责任。

五、违规处理

发现以下行为将立即封禁 Key：

  • 超出频率限制的恶意请求；
  • 转售或将数据用于商业产品；
  • 伪造来源、规避限制；
  • 其他破坏服务稳定的行为。

六、协议变更

我们保留随时修改本协议及 API 接口的权利，变更前会尽量提前通知。
