举报与反馈

发现问题？有建议？请告诉我们，你的每一条反馈都让 RailGo 更好。

反馈渠道

请通过以下任一方式联系我们：

mail
电子邮件 railgo@azstudio.dev
forum
QQ 群 加入官方交流群
bug_report
GitHub Issue 提交 bug 或功能请求

反馈时请提供

  • 设备信息：机型、系统版本
  • RailGo 版本：在「设置 → 关于」中查看
  • 问题复现步骤：越详细越好
  • 截图或录屏：如有请附上
warning

举报请针对 RailGo 软件本身的问题。铁路运营相关投诉请向 12306 或对应铁路局反映。

响应时间

我们会在收到反馈后尽快处理。一般问题 3 个工作日内回复，复杂问题可能需要更长时间，敬请谅解。
